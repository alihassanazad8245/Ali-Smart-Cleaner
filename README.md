# 🧹 Ali Smart Cleaner

**Ali Smart Cleaner** is a lightweight Windows system-cleaning utility built with **Batch scripting**.

It provides a simple menu-driven interface for cleaning temporary files, cache, and other unnecessary system junk — while also providing useful tools such as disk-space information and activity logs.

> ⚡ **Simple. Fast. Lightweight. Built for Windows.**

---

## ✨ Features

### 🧼 Cleaning Tools

* ⚡ **Normal Clean** — Fast and safe cleanup for common temporary files.
* 🔥 **Deep Clean** — Performs a more advanced cleanup of unnecessary junk.
* 🎯 **Selective Cleaning** — Choose specific cleanup operations instead of running everything.

### 🛠️ Utility Features

* 💾 **Disk Space Viewer** — Quickly check available disk space.
* 📜 **Activity Logging** — Keeps track of cleaning activity.
* 🔍 **Scan Interface** — Provides a visual system-scan experience before cleaning.
* 🖥️ **Interactive Menu** — Easy-to-use command-line interface.

### 🛡️ Safety

* Designed to target temporary/cache and unnecessary files.
* Does not intentionally remove personal documents.
* Administrator privileges are recommended for full functionality.

# 🚀 Quick Start

You don't need to install a complicated setup.

### 1. Clone the Repository

Open **Command Prompt**, **PowerShell**, or **Windows Terminal** and run:

```bash
git clone <YOUR-GITHUB-REPOSITORY-URL>
```

### 2. Open the Project Folder

```bash
cd Ali-Smart-Cleaner
```

### 3. Run the Cleaner

```bat
cleaner.bat
```

The cleaner will start and display the main menu.

> 💡 **Tip:** For full functionality, run the batch file as **Administrator**.

---

## ⚡ Quick Run

## 🪟 Running Without Git

Don't want to use Git?

1. Open the repository on GitHub.
2. Click **Code → Download ZIP**.
3. Extract the ZIP file.
4. Open the extracted `Ali-Smart-Cleaner` folder.
5. Right-click `cleaner.bat`.
6. Select **Run as administrator**.

That's it. 🧹

## 🔐 Safety & Usage

Ali Smart Cleaner is designed to clean temporary and unnecessary system data.

However, because the application performs file-system cleanup operations, **always review what a cleaning utility does before running it on important systems**.

### Recommended practice

* Save your important work before cleaning.
* Close applications that may be using temporary files.
* Run as Administrator when required.
* Do not modify the batch file unless you understand the commands being executed.

> ⚠️ **Important:** Like any system-cleaning utility, use it responsibly. The exact files and locations cleaned depend on the operations implemented in `cleaner.bat`.
